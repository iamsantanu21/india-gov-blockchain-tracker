Each zip holds the whole dataset: the CSV tables, `datapackage.json`, the Excel and SQLite editions, the map file, the build tools, an offline copy of the dashboard (`dashboard.html`) and the documentation.

The zip here is built from this repository with `python3 tools/make_release.py`. Its data are identical to the version 1.1.0 deposit on Zenodo; the documentation and dashboard inside it carry the DOIs, which did not exist yet when the deposit was made. Zenodo keeps the official deposited copy of every version.

Cite: Mondal, S., & Chithralekha, T. (2026). *Blockchain in Indian Government Administration: A Project-Level Dataset (2017–2026)* [Data set]. Zenodo. https://doi.org/10.5281/zenodo.23136332

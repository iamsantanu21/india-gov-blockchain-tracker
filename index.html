Data & method

A Frictionless Data Package: normalised CSV tables with keys and controlled vocabularies, so new projects, stage events and snapshots can be added and validated. This dashboard reads the same files.

  1. Add the body to bodies.csv if it is new, then a row to projects.csv with the next free ID.
    2. 
          
  2. Add each dated event to stage_events.csv and each source to sources.csv and project_sources.csv.
    3. 
          
  3. Run python3 tools/build.py. It checks types, codes and links, then rebuilds the derived files. The full steps are in UPDATE_GUIDE.md inside the .zip.
    4. 
          
  4. Publish the changed CSVs. The dashboard recalculates every chart from them.

Adding data
    
          
  1. Add the body to bodies.csv if it is new, then a row to projects.csv with the next free ID.
    2. 
          
  2. Add dated events to stage_events.csv and sources to sources.csv and project_sources.csv.
    3. 
          
  3. Run python3 tools/build.py. It checks every code, link and date, and rebuilds all_projects.csv, the combined table this tracker reads.
    4. 
          
  4. Publish the changed CSVs. Every chart recalculates from them.
